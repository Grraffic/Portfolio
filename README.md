# Personal Portfolio

A full-stack developer portfolio built with **React + TypeScript + Tailwind CSS** (frontend), **Express + Node.js** (backend), and **Supabase** (database).

## Features
- 🎨 Dark-mode responsive design
- 📂 Display projects with tech stack badges
- ➕ Add / Edit / Delete projects from Admin page
- 🔍 Filter projects by technology

## Quick Start

See [docs/SETUP.md](docs/SETUP.md) for full setup instructions.

```bash
# Backend
cd backend && npm install && npm run dev

# Frontend (new terminal)
cd frontend && npm install && npm run dev
```

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React, TypeScript, Vite, Tailwind CSS v3 |
| Backend | Node.js, Express |
| Database | Supabase (PostgreSQL) |
